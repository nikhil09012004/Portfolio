# Nikhil's Portfolio Website

A modern, responsive portfolio website showcasing data analytics and machine learning projects.

## Features

- Dark/Light theme toggle
- Smooth scroll animations
- Responsive design for all devices
- Interactive project cards
- Contact form
- Professional layout

## Setup Instructions

1. Add your images to the `images/` folder:
   - `profile.jpg` - Your profile photo
   - `bank-loan-dashboard.png` - Bank Loan Dashboard project screenshot
   - `loan-prediction.png` - Loan Prediction System project screenshot

2. (Optional) Add your resume as `Nikhil_Resume.pdf` in the root folder

3. Open `index.html` in your browser to view the portfolio

## Customization

- Edit `index.html` to update content
- Modify `style.css` to change colors and styling
- Update `script.js` to adjust animations and interactions

## Technologies Used

- HTML5
- CSS3 (with CSS Variables for theming)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts (Inter)

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
