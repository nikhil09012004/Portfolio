# Certificate Images

Add your certificate screenshots to this folder with the following names:

1. **nptel-privacy-security.jpg** - Privacy and Security in Online Social Media certificate
2. **coursera-powerbi.jpg** - From Excel to Power BI certificate
3. **lpu-dsa.jpg** - Data Structures and Algorithms certificate
4. **lpu-dsa-cpp.jpg** - DSA using C++ certificate

## Tips for Certificate Screenshots:

- Use high-quality images (at least 1200px width)
- Save as JPG or PNG format
- Crop to show the main certificate content
- Ensure text is readable
- Keep file sizes reasonable (under 500KB each)

## How to Take Screenshots:

1. Open your certificate in full screen
2. Use Windows Snipping Tool (Win + Shift + S) or screenshot tool
3. Crop to remove unnecessary borders
4. Save with the exact filename mentioned above
