# Project Screenshots

Add your project screenshots to this folder with the following names:

## Required Images:

1. **bank-loan-dashboard.png** - Screenshot of your Bank Loan Dataset Analysis Dashboard
   - Show the Power BI dashboard with charts and KPIs
   - Recommended size: 1200x800px or similar aspect ratio

2. **loan-prediction.png** - Screenshot of your Loan Prediction System
   - Show the prediction interface or results visualization
   - Recommended size: 1200x800px or similar aspect ratio

## Tips for Project Screenshots:

### For Power BI Dashboard:
- Open your dashboard in full screen
- Capture the main view with all key visualizations
- Make sure charts, KPIs, and filters are visible
- Use high contrast/quality settings

### For Loan Prediction System:
- Show the main interface or prediction results
- Include any charts, confusion matrix, or accuracy metrics
- Capture the most impressive/informative view

## How to Take Screenshots:

1. **Windows Snipping Tool:**
   - Press `Win + Shift + S`
   - Select the area to capture
   - Paste in Paint or image editor
   - Save as PNG with the correct filename

2. **Full Screen Capture:**
   - Press `PrtScn` (Print Screen)
   - Paste in Paint
   - Crop to desired area
   - Save as PNG

3. **Browser Screenshot (for web apps):**
   - Use browser extensions like "Full Page Screen Capture"
   - Or use F12 Developer Tools → Device Toolbar → Capture Screenshot

## File Format:
- Use PNG for better quality (recommended)
- Or JPG if file size is a concern
- Keep file size under 1MB for faster loading
